# Python Projects Repository

This repository contains Python GUI applications built using **Tkinter** and other useful libraries.

---

## Projects Included

### 1. College Admission Form
* **Description:** A desktop-based college admission form interface built using Tkinter for [St. Thomas' College of Engineering and Technology](https://github.com/AYUSHMONDAL75/Python-Projects/blob/main/College%20admission%20form). It collects comprehensive student details (personal info, guardian details, marks, and department selection) and saves the submitted data directly into an Excel sheet.
* **Key Features:**
  * Clean form UI with custom frames, fonts, and styling.
  * Department selection options (AIML, CSE, IT, ECE, EE).
  * Automatic data export and appending to `college_admission.xlsx` using `pyexcel`.
* **Main File:** `college_admission.py`

### 2. HS Result Showing (School)
* **Description:** A utility tool designed to display and manage Higher Secondary (HS) school results.
* **Main File:** `HS result Showing(school)`
